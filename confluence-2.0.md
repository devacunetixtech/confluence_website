# **CONFLUENCE 2.0 — WEBSITE REDESIGN & DEVELOPMENT PROMPT**

Act as a **Principal Product Designer, Senior Frontend Engineer, and Web3 Event Experience Designer** tasked with redesigning and upgrading the official website for **Confluence 2.0**, the annual flagship event of Blockchain Club LAUTECH (BCL).

The goal is NOT to create a generic Web3 conference website.

The goal is to evolve the existing Confluence identity from **1.0 → 2.0**: more mature, more intentional, more human, more premium, and significantly more memorable while retaining the recognizable colors, visual DNA, and credibility of the existing Confluence brand.

---

## **1\. REFERENCE THE EXISTING WEBSITE**

Study both existing websites before making design decisions:

**Confluence 1.0**  
[https://confluence.blockchainlautech.club/2025](https://confluence.blockchainlautech.club/2025)

**Confluence 2.0 current placeholder**  
[https://confluence.blockchainlautech.club/](https://confluence.blockchainlautech.club/)

Use Confluence 1.0 as the primary reference for:

* Existing brand colors  
* Typography direction  
* Logo treatment  
* Existing visual language  
* Section structure  
* Event identity  
* Existing animations/interactions  
* How speakers, sponsors, and event information are presented

Do NOT simply copy the 1.0 website.

Instead, treat 1.0 as the foundation and create a clearly recognizable **2.0 evolution**.

The result should feel like:

> **Confluence 1.0, but grown up.**

---

# **2\. CORE CREATIVE DIRECTION**

The central theme for Confluence 2.0 is:

## **CODE.**

## **CREATE.**

## **CONNECT.**

These three words should become the visual and narrative backbone of the website.

They represent three dimensions of Confluence:

**CODE**  
Builders, developers, technology, innovation, hackathons, products and technical experimentation.

**CREATE**  
Founders, creatives, ideas, art, startups, entrepreneurship and purposeful creation.

**CONNECT**  
Community, people, conversations, relationships, collaboration, networking and the human side of technology.

The website should continuously reinforce this concept without becoming repetitive.

---

# **3\. DESIGN PHILOSOPHY**

Create a website that feels:

* Premium  
* Modern  
* Editorial  
* Human  
* Confident  
* Youthful but mature  
* Technically sophisticated  
* Community-driven  
* African  
* Nigerian  
* Authentic  
* Minimal but expressive

Avoid the stereotypical Web3 aesthetic.

STRICTLY AVOID:

* Generic neon cyberpunk  
* Excessive glowing gradients  
* Random 3D crypto objects  
* Overused blockchain graphics  
* Generic AI-generated futuristic imagery  
* Excessive glassmorphism  
* Cluttered dashboards  
* Too many gradients  
* Excessive animated particles  
* “AI slop” aesthetics  
* Making everything look like a crypto trading platform

Instead, take inspiration from the quality and restraint of modern brands such as:

* Linear  
* Stripe  
* Notion  
* Vercel  
* Apple  
* Figma  
* modern editorial magazines  
* premium cultural festivals  
* contemporary African creative brands

The design should communicate:

> **Technology is powerful. People are the point.**

---

# **4\. COLOR SYSTEM**

Retain the current Confluence 1.0 color identity as the foundation.

Do NOT completely replace the existing brand colors.

Instead:

* Audit the current color palette from the existing website.  
* Keep the recognizable primary colors.  
* Refine their usage for better contrast and hierarchy.  
* Introduce subtle supporting neutrals where necessary.  
* Use color intentionally to distinguish the three pillars:

**CODE → technology/building**

**CREATE → creativity/ideas**

**CONNECT → people/community**

The colors should feel cohesive rather than like three unrelated themes.

Use generous neutral space, strong typography, crisp borders and controlled color accents.

---

# **5\. TYPOGRAPHY**

Typography should be one of the strongest visual elements.

Use a modern sans-serif typeface such as:

* Inter  
* Manrope  
* Geist  
* Satoshi  
* Plus Jakarta Sans

Use:

* Large editorial headlines  
* Tight but readable typography  
* Strong contrast between headings and supporting copy  
* Large numbers for statistics  
* Generous spacing  
* Clear information hierarchy

The hero headline should feel like a statement rather than simply another event title.

# **24\. PERFORMANCE**

The website should feel extremely fast.

Prioritize:

* Optimized images  
* Lazy loading  
* Minimal JavaScript  
* Lightweight animations  
* Efficient component architecture  
* Proper responsive images  
* Good Core Web Vitals

Do not sacrifice performance for visual effects.
